## Menu typography and background

- `fonts/PixelifySans.ttf`: Pixelify Sans by Stefie Justprince / The Pixelify Sans Project Authors. Bundled unmodified from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/pixelifysans) under the SIL Open Font License 1.1; see `fonts/OFL-PixelifySans.txt`. The variable font supports weights 400–700.
- `doodle-blue.png`: original blue doodle tile generated with the built-in imagegen tool using the user's second image as a style reference.
- `../branding.css`: shared live-text wordmark with square pixel letterforms, colorful fills and hard-edged outlines made from integer shadow offsets. Letters sit on a straight baseline to preserve the pixel shapes. The two-line title remains accessible text, while controls keep their more readable UI font.
- Both assets ship locally. Content-script CSS uses Chrome's [predefined extension-ID substitution](https://developer.chrome.com/docs/extensions/reference/api/i18n#predefined_messages) for asset URLs; the manifest exposes only the required artwork/font to supported game origins.

### Background generation prompt

Use case: stylized-concept. Asset type: seamless repeating square background tile for a drawing-game Chrome extension menu. Input images: image 1 is lettering reference, IGNORE the lettering for this asset; image 2 is the BLUE DOODLE BACKGROUND style reference. Generate an ORIGINAL arrangement of different playful hand-drawn doodles inspired by image 2. Uniform flat medium royal blue ground approximately #28569a, dark navy-blue doodle outlines approximately #174383, modest contrast. Dense but airy scattered small drawings in varied rotations: an ink quill, folded paper boat, umbrella, cup, comet, friendly ghost, headphones, sprout, butterfly, mountain, paint palette, ice cream, planet, little robot, snail, balloon, key, cloud. Unfilled simple outlines, consistently chunky slightly rough pixel-stepped strokes like low-resolution mouse-drawn pictionary sketches, flat 2D raster aesthetic. Even distribution over the entire square, objects small enough to create texture behind a compact UI, seamless matching edges for a repeating tile. Background only. No text, no letters, no logo, no border, no gradients, no shading, no light-colored objects, no central hero object, no interface elements. Keep all linework dark blue on medium blue; closely match image 2's quiet monochrome character while making different doodles and composition.
